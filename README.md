# order-pilot
this software help to automatically generate order admin touch

- `packages/orderpilot`: the Messenger order bot as an npm package. Install it in any Node.js app, give it a Facebook Page's details and products, and customers order in Messenger. See [its README](packages/orderpilot/README.md).
- `api`: the backend (Express): products and admin orders API, with the bot plugged in from `packages/orderpilot`.
- `web`: the admin dashboard (Next.js).
